# UniCareer — демонстрационная версия

Локальная учебная платформа для IT-выпускников: вакансии, резюме, отклики и кабинеты выпускника, работодателя и университета.

## Запуск на Windows

1. Установите Python 3.10 или новее: https://www.python.org/downloads/windows/
   При установке включите «Add python.exe to PATH».
2. Распакуйте архив в любую папку.
3. Запустите `start_windows.bat`.
4. Откройте http://localhost:8000 в браузере.

Остановка сервера — `Ctrl+C` или закрытие окна консоли.

Если порт 8000 занят, запустите `start_windows.bat 8080` и откройте http://localhost:8080.

## Демо-аккаунты

Пароль для всех аккаунтов: `12345678`

- `graduate@unicareer.kz` — выпускник
- `employer@unicareer.kz` — работодатель
- `university@unicareer.kz` — университет

При первом запуске база создаётся автоматически: 5 демо-вакансий и три аккаунта. Файл базы `unicareer.sqlite3` появляется рядом с `server.py`.

Чтобы сбросить демо-данные, закройте сервер, удалите `unicareer.sqlite3`, `unicareer.sqlite3-shm` и `unicareer.sqlite3-wal`, затем запустите снова.

## Состав

- `server.py` — локальный HTTP-сервер и SQLite на стандартной библиотеке Python, без сторонних пакетов;
- `public/index.html` — интерфейс приложения;
- `start_windows.bat` — запуск для Windows.

## Важно

Это учебный локальный прототип. Пароли не защищены, база хранит общий JSON. Не используйте реальные персональные данные и не публикуйте проект в интернет.
